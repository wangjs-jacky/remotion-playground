# Remotion Playground

A comprehensive demo project covering core Remotion features, organized into 9 categories.

[中文文档](./README_CN.md)

## Demo Categories

| Folder | Compositions |
|--------|-------------|
| 01-Animations | FadeIn, ScaleRotate, Spring, Easing |
| 02-TextAnimations | Typewriter, WordHighlight, StaggeredText |
| 03-Media | Video, Audio, Image, GIF, Lottie, Font |
| 04-Sequencing | Sequence, Series, Transitions, Trimming |
| 05-Charts | BarChart, PieChart, LineChart |
| 06-Stills | Thumbnail |
| 07-Parameterized | Schema-driven dynamic props |
| 08-Showcase | ChromeTiltInteractive, VideoRotation |
| 09-BurgerAd | Terminal Noir burger advertisement |

## Getting Started

```bash
npm install
npm start        # Open Remotion Studio
npm run build    # Render FadeIn demo to out/demo.mp4
```

## Requirements

- Node.js 18+
- Remotion 4.0.441
