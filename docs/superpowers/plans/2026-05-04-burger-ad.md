# Terminal Noir 汉堡广告视频 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan.

**Goal:** 在 jacky-remotion 项目中实现 Terminal Noir 风格的 15 秒汉堡广告程序化动画视频。

**Architecture:** 状态机驱动的场景管理器根据帧号切换 8 个场景组件。SVG 几何食材 + 霓虹发光 + 蒸汽粒子构成 Terminal Noir 美食风格。

**Tech Stack:** Remotion 4.0, React 19, TypeScript, CSS-in-JS (inline styles)
