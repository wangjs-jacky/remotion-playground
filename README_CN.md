# Remotion Playground

覆盖 Remotion 核心功能的演示项目，共 9 个分类。

[English](./README.md)

## 演示分类

| 文件夹 | 内容 |
|--------|------|
| 01-Animations | 淡入、缩放旋转、弹簧动画、缓动函数 |
| 02-TextAnimations | 打字机、词高亮、错落文字 |
| 03-Media | 视频、音频、图片、GIF、Lottie、字体 |
| 04-Sequencing | Sequence、Series、转场、Trim |
| 05-Charts | 柱状图、饼图、折线图 |
| 06-Stills | 静态图（Thumbnail） |
| 07-Parameterized | 通过 Schema 驱动动态 Props |
| 08-Showcase | Chrome 3D 倾斜交互、视频旋转 |
| 09-BurgerAd | Terminal Noir 风格汉堡广告 |

## 快速开始

```bash
npm install
npm start        # 打开 Remotion Studio
npm run build    # 渲染 FadeIn 演示到 out/demo.mp4
```

## 环境要求

- Node.js 18+
- Remotion 4.0.441
